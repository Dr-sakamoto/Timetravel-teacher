# 時空最強クラス決定戦 〜タイムトラベル・ティーチャー〜

歴史上の偉人や恐竜を自分のクラスに転校させて「時空最強のクラス」を作る、2〜5人用のボードゲームアプリ。
カタンの「自分の番でなくても毎回得点チャンスがある」感じと、桃鉄の「すごろく移動＋長期戦」を合わせたゲーム性です。

1台の端末を回して遊ぶホットシート式と、みんなのスマホをつないで遊ぶ**通信対戦**があります。CPUプレイヤーも入れられるので1人でも遊べます。

### 通信対戦（みんなのスマホで）

1. 1人がタイトルの「📱 通信対戦」→ 名前を入れて「🏠 ルームを作る」。5桁の**部屋番号**が出るので、みんなに伝える
2. ほかの人は同じく「📱 通信対戦」→「🔢 部屋番号で入る」に部屋番号を入れて「ルームに入る」（ルームを作った人が「🔗 招待リンクを送る」で送ったリンクを開いてもいい）
3. 足りない席は「🤖 CPUを足す」で埋めて、ルームを作った人が「ゲーム開始！」

- 自分のスマホには自分の教室が手前に出て、自分の番の時だけ操作できる（ほかの人の番は「⏳ ○○ の番…」）
- ルームを作った人のスマホがゲームを進める（CPUもこのスマホが動かす）ので、その人はアプリを開いたままにしておく
- 通信が切れても自動でつなぎ直す。読み込み直しても同じルーム・同じ席に戻れる。通信が切れた人の操作を待って止まったときだけ、ルームを作った人の画面の「1手だけ代わりに進める」でその1手だけCPUに進めてもらえる（席をCPUに渡すことはないので、その人の手番が勝手に進むことはない）
- ルームを作った人が抜けても、「📱 通信対戦」→「前のルームを再開」で続きから遊べる（同じ部屋番号で開き直すので、参加者は自動でつながり直す）
- 通信は WebRTC（[PeerJS](https://peerjs.com/)）でスマホどうしを直接つなぐ。つなぐ時の仲介には PeerJS の無料サーバーを使うので、自前のサーバーはいらない

**遊ぶ：https://timetravel-teacher.vercel.app/** （PWA対応。Chrome/Edgeのアドレスバーの「インストール」でPCアプリとして使え、オフラインでも動きます）

スマホは**横向き**で遊ぶ想定です（卓全体が1画面に収まります。縦向きだと横にするよう案内が出ます）。

画面には自分の教室と、手番の人の教室だけが出ます。ほかの人の教室は小さく畳まれていて、タップするとポップアップで見られます。

## 遊び方

1. **最初の6人を引く** — 全員で順番に現代の普通の生徒（N・17種×2枚。アイコンの構成は1人ずつ違う）の山から1枚ずつ、完全ランダムに引く。教室は9席。スタート以降に現代から来るのは、現代の学期の転校生（R以上の8人）だけ。
2. **係を決める** — 係は🎖️学級委員長👑・🖌️文化委員🎨・✏️学習係📚・🏅体育委員🏃の4種類で、1つの係に1人ずつ。
   1年1学期は1種だけで、学期の頭にまだ解放していない係から好きなものを1種選んで解放していく（最大4種・2年1学期）。解放した係はずっと使える。
   係に就いた子は、その係のアイコンが2倍に数えられる。学期の頭に決め直せる。
   プレイマットの左側にある4つの「係の場」に生徒のカードを置くと、その子がその係になる（ドラッグで動かすか、タップで持ち上げて置き場をタップ）。係の場どうし・係の場と座席のカードは入れ替わる。まだ解放していない係の場（🆕）をタップすると、その係を解放する。
3. **手番：場のカードを1枚取る**（プレイヤーは同じ学校の別のクラスの担任）
   - 卓の中央にカードが4枚、表向きで並んでいる（場）。手番の人はここから1枚取る。取りたいものがなければ1枚を捨てて見送ってもいい
   - **無料で取れる**：授業（📚数学・🏃体育・🎨美術・🙋学活の時間。クラス全員のそのアイコンの合計個数＋係ボーナスがその場で入る）・カチコミ👊（他のクラスを1つ選んで、自分の👊の数（＋係ボーナス）×3だけ減点させる。👊を持つ子がいないと取れない）・クラス替え🔁（自分の生徒1人と、他のクラスの係に就いていない生徒1人を入れ替える。印刷されたアイコンの数が同じ子どうしだけ。グッズの＋1は数えない）
   - **クラスポイントを払って取る**：人物（N 2点／R 4点／SR 12点／SSR 24点。短い試合なら安いR、長い試合ならSSRが狙い目。満席なら係に就いていない子を1人転校させて迎える）・グッズ（2点。生徒1人に装備してアイコン＋1、1人1つまで。共通3種＋時代ごとに2種）・サイボーグ化（2点・未来のみ）。「今すぐ点を取るか、点を払って将来の戦力を買うか」が悩みどころ
   - 取ったら山札から場を補充する。このとき**ゲリラ**をめくったら、その場で起こる（誰も避けられない）
     - 共通イベント（全クラス）：抜き打ちテスト（📚）・授業参観（👑で得点、👊で減点）・持久走大会（🏃）・合唱コンクール（🎨）
     - 時代イベント（全クラス・2種×2枚）：時代ごとにものを言う力が違う。その時代出身の子は2倍
       - 現代以外の時代には、点の数え方ではなく起こることそのものが違う「その時代だけのイベント」が1種ずつある
         - 白亜紀 🦴縄張り争い：👊が一番多いクラスが、一番少ないクラスから生徒を1人奪う
         - 古代エジプト 🔺ギザの大ピラミッド建設：全クラス共同。🏃の合計が6×クラス数以上なら全クラス+6（🏃が一番少ないクラスはサボりで0）、届かなければ全クラス−3
         - ギリシャ・ローマ 🏺陶片追放：全校でアイコンが一番多い子が1人、追放される
         - 古代中国 📜科挙：各クラスの📚が一番多い子が受験。📚3以上で合格して📚が1つ増える（ずっと）
         - 平安 🌕藤原道長の宴：👑が一番多いクラスに、ほかの全クラスが3点ずつ贈る
         - 中世・ルネサンス 🏇馬上槍試合：各クラスの👊が一番多い子どうしの一騎打ち。1位+10、最下位の子は落馬して転校
         - 戦国 🏯人質：各クラスの、係に就いていない👑が一番多い子が、となりの席のクラスへ移る
         - 江戸・幕末 🎫富くじ：全クラスが3点ずつ出し、くじで当たった1クラスが総取り
         - 近代 🏅ノーベル賞：全校で📚が一番多い子1人が受賞し、その子のクラスに+12
         - 未来 👽火星人の侵略：空いている席に、アイコンのない火星人が座る（＋場から取れる🦾サイボーグ化）
         - 現代は「いつもの学校」なので特別なイベントはない
     - 襲来（全クラス・時代ごとに1枚）：クラスの👊の数−敵の強さ（その時代出身の子は2倍）。白亜紀の恐竜（強さ9）や戦国の本能寺の変（強さ8）は強い
     - 転校📦：全クラスが、係に就いていない生徒を1人ずつ必ず手放す（1枚だけ。山札に入るのは学期の3回に2回）
   - 👊の子はテストや授業参観でいつも足を引っぱるが、カチコミと襲来では頼りになる
   - 人物カードは学期ごとに最大7枚（その時代のカードプールに残っている子だけ）。生徒はどの時代も有限で、人物ごとにアイコンの構成が被らないようにしてある
   - 山札の内訳（例：現代の学期、計45枚。転校が入らない学期は44枚）：授業19（📚5・🏃5・🎨5・👑4）／カチコミ3／共通イベント4／転校1・クラス替え1／グッズ5（共通3＋時代2）／時代イベント4＋襲来1／人物7。ゲーム中は中央の「捨て札・内訳」で残り枚数を確認できる
4. **時代** — 1年に3つ、1学期に1つずつ巡る。1年目の1学期は現代、あとはランダム。何が有利かは数字ではなく、学期の頭に読み上げられる時代の空気（白亜紀なら「理屈も作法も通じない。ただ強い者だけが生き残る時代」）から読み取る。
5. **決まったイベント（全員）** — 学期末の定期テスト（📚の合計個数−👊を持つ子1人につき1で順位、5／3／2／1点）、最後に卒業式（クラス全員のアイコン総数、順位点×3）。8月は夏休みで手番なし。
6. 1年／2年／3年が終わった時点でクラスポイントが一番多い先生の勝ち。

## 生徒カード

書いてあるのは **アイコン**（📚勉強・🏃運動・🎨芸術・👑人望・👊喧嘩）だけ。同じアイコンが並ぶほど得意で、1枚に最大5個（N 1〜2個／R 2〜3個／SR 3〜4個／SSR 4〜5個）。グッズを装備すると1つ増える。古代中国の科挙に合格しても1つ増える（5個まで）。
👊はヤンキーだけが持ち、ヤンキーの約半分は👊のみ（たまに🏃や📚も持つ）。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # ゲームロジックのテスト（全員CPUで完走するシミュレーション含む）
npm run build   # dist/ に静的ファイルを出力
```

- `src/game/` — ゲームロジック（React非依存）。`engine.ts` が状態遷移、`ai.ts` がCPU思考
- `src/game/data/` — カード・時代・係・クラス・イベントのデータ。カードを増やすならここ
- `src/ui/` — 画面
- `src/net/` — 通信対戦。`host.ts` がルームを作った人の端末（ゲームを進めて全員に状態を配る）、`guest.ts` が参加した人の端末（操作を送る）、`protocol.ts` がやりとりの型と「今その人が操作してよいか」の判定

通信対戦の仲介サーバーを自前の [PeerJS Server](https://github.com/peers/peerjs-server) にする時は、ビルド時に `VITE_PEER_HOST`・`VITE_PEER_PORT`・`VITE_PEER_PATH`・`VITE_PEER_SECURE` を指定します。

進行状況はブラウザの localStorage に自動保存され、タイトル画面の「続きから」で再開できます。
`main` ブランチへの push で GitHub Pages にデプロイされます（`.github/workflows/deploy.yml`）。
