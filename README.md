# 時空最強クラス決定戦 〜タイムトラベル・ティーチャー〜

歴史上の偉人や恐竜を自分のクラスに転校させて「時空最強のクラス」を作る、2〜5人用のボードゲームアプリ。
カタンの「自分の番でなくても毎回得点チャンスがある」感じと、桃鉄の「すごろく移動＋長期戦」を合わせたゲーム性です。

1台の端末を回して遊ぶホットシート式。CPUプレイヤーも入れられるので1人でも遊べます。

**遊ぶ：https://timetravel-teacher.vercel.app/** （PWA対応。Chrome/Edgeのアドレスバーの「インストール」でPCアプリとして使え、オフラインでも動きます）

スマホは**横向き**で遊ぶ想定です（卓全体が1画面に収まります。縦向きだと横にするよう案内が出ます）。

画面には自分の教室と、手番の人の教室だけが出ます。ほかの人の教室は小さく畳まれていて、タップするとポップアップで見られます。

## 遊び方

1. **最初の3人を引く** — 全員で順番に「現代」のカードプール（N）から1枚ずつ、完全ランダムに引く。教室は9席。
2. **係を決める** — 係は✏️学習係📚・🏅体育委員🏃・🖌️文化委員🎨・🎖️学級委員長👑・🛡️風紀委員👊の5種類。
   係の席は1年1学期は1人だけで、学期が進むごとに1席ずつ増え、最大6人（2年3学期）。1つの係に2人まで、係の種類は3つまで。
   係に就いた子は、その係のアイコンが2倍に数えられる。学期の頭に決め直せる。
3. **手番：1人1枚ずつ山札をめくる**（効果はめくった人だけ。カチコミだけは相手を減点させる）
   - 通常カード（○○の時間）：📚数学・🏃体育・🎨美術・🙋学活の時間。クラス全員のそのアイコンの合計個数（＋係ボーナス）が入る。全時代共通
   - カチコミ👊：他校を1つ選び、自分のクラスの👊の数だけその学校を減点させる
   - 共通イベント：抜き打ちテスト（📚−👊）・授業参観（👑−👊）・持久走大会（🏃−人数）・合唱練習（🎨−人数）・ケンカ騒ぎ（👊−👑）。クラスの状況でプラスにもマイナスにもなる
   - 転校📦：いらない生徒を別のクラスに押しつける／交換留学🔁：係に就いていない生徒どうしを他校と交換
   - グッズ：生徒1人に装備してアイコン＋1（1人1つまで）。共通3種（参考書📚・スポーツシューズ🏃・絵の具セット🎨）＋時代ごとに2種
   - 時代イベント（2種×2枚）：クラス全員のそのアイコンの合計。その時代出身の子は2倍。時代によって得をする能力が変わる
   - 襲来（時代ごとに1枚）：クラスの👊の数−敵の強さ（その時代出身の子は2倍）。白亜紀の恐竜（強さ9）や戦国の野武士（強さ8）は強く、撃退できれば大きくプラス、守れなければ大きくマイナス
   - 人物カード：めくったらその子がそのまま転入（学期ごとに最大7枚。その時代のカードプールに残っている子だけ）。満席なら捨て札にしてもう1枚めくる
   - 生徒はどの時代も有限で、現代も1つのカードプール（N 26種×2枚＋R以上8種×1枚＝60枚）
   - 山札の内訳（現代の学期、計47枚）：通常19（📚5・🏃5・🎨5・👑4）／カチコミ3／共通イベント5／転校2・交換留学1／グッズ5（共通3＋時代2）／時代イベント4＋襲来1／人物7。ゲーム中は中央の「捨て札・内訳」で残り枚数を確認できる
4. **時代** — 1年に3つ、1学期に1つずつ巡る。1年目の1学期は現代、あとはランダム。
5. **決まったイベント（全員）** — 学期末の定期テスト（📚の合計個数−👊を持つ子1人につき1で順位、5／3／2／1点）、8月の夏休み合宿（2学期の時代から全員に1人ずつランダムに転入）、最後に卒業式（クラス全員のアイコン総数、順位点×3）。
6. 1年／2年／3年が終わった時点でクラスポイントが一番多い先生の勝ち。

## 生徒カード

書いてあるのは **アイコン**（📚勉強・🏃運動・🎨芸術・👑人望・👊喧嘩）だけ。同じアイコンが並ぶほど得意で、1枚に最大5個（N 1〜2個／R 2〜3個／SR 3〜4個／SSR 4〜5個）。グッズを装備すると1つ増える。
👊はヤンキーだけが持ち、ヤンキーの約半分は👊のみ（たまに🏃や📚も持つ）。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # ゲームロジックのテスト（全員CPUで完走するシミュレーション含む）
npm run build   # dist/ に静的ファイルを出力
```

- `src/game/` — ゲームロジック（React非依存）。`engine.ts` が状態遷移、`ai.ts` がCPU思考
- `src/game/data/` — カード・時代・係・クラス・イベントのデータ。カードを増やすならここ
- `src/ui/` — 画面

進行状況はブラウザの localStorage に自動保存され、タイトル画面の「続きから」で再開できます。
`main` ブランチへの push で GitHub Pages にデプロイされます（`.github/workflows/deploy.yml`）。
