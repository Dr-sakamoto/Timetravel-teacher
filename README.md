# 時空最強クラス決定戦 〜タイムトラベル・ティーチャー〜

歴史上の偉人や恐竜を自分のクラスに転校させて「時空最強のクラス」を作る、2〜5人用のボードゲームアプリ。
カタンの「自分の番でなくても毎回得点チャンスがある」感じと、桃鉄の「すごろく移動＋長期戦」を合わせたゲーム性です。

1台の端末を回して遊ぶホットシート式と、みんなのスマホをつないで遊ぶ**通信対戦**があります。CPUプレイヤーも入れられるので1人でも遊べます。

### 通信対戦（みんなのスマホで）

1. 1人がタイトルの「📱 通信対戦」→ 名前を入れて「🏠 ルームを作る」。5桁の**部屋番号**が出るので、みんなに伝える
2. ほかの人は同じく「📱 通信対戦」→「🔢 部屋番号で入る」に部屋番号を入れて「ルームに入る」（ルームを作った人が「🔗 招待リンクを送る」で送ったリンクを開いてもいい）
3. 足りない席は「🤖 CPUを足す」で埋めて、ルームを作った人が「ゲーム開始！」

- 自分のスマホには自分の教室が手前に出て、自分の番の時だけ操作できる（ほかの人の番は「⏳ ○○ の番…」）
- ルームを作った人のスマホがゲームを進める（CPUもこのスマホが動かす）ので、その人はアプリを開いたままにしておく
- 通信が切れても自動でつなぎ直す。読み込み直しても同じルーム・同じ席に戻れる。通信が切れた人の操作を待って止まったときだけ、ルームを作った人の画面の「1手だけ代わりに進める」でその1手だけCPUに進めてもらえる（席をCPUに渡すことはないので、その人の手番が勝手に進むことはない）
- ルームを作った人が抜けても、「📱 通信対戦」→「前のルームを再開」で続きから遊べる（同じ部屋番号で開き直すので、参加者は自動でつながり直す）
- 通信は東京の中継サーバー（[Supabase Realtime](https://supabase.com/docs/guides/realtime)）を通す。スマホどうしを直接つながないので、回線（学校・会社のWi-Fiやスマホの回線）によってつながらない、ということが起きにくい

**遊ぶ：https://timetravel-teacher.vercel.app/** （PWA対応。Chrome/Edgeのアドレスバーの「インストール」でPCアプリとして使え、オフラインでも動きます）

スマホは**横向き**で遊ぶ想定です（卓全体が1画面に収まります。縦向きだと横にするよう案内が出ます）。

画面には自分の教室と、手番の人の教室だけが出ます。ほかの人の教室は小さく畳まれていて、タップするとポップアップで見られます。

## 遊び方

1. **最初の6人を引く** — 全員で順番に現代の普通の生徒（N・17種。1種3枚ずつで、📚📚・🏃🏃のように同じアイコンが2個並んだ子だけ2枚ずつ。アイコンの構成は1人ずつ違う）の山から1枚ずつ、完全ランダムに引く。教室は9席。スタート以降に現代から来るのは、現代の学期の転校生（R以上の7人）だけ。
2. **係を決める** — 係は🎖️学級委員長👑・🖌️文化委員🎨・✏️学習係📚・🏅体育委員🏃の4種類で、1つの係に1人ずつ。
   1年1学期は1種だけで、学期の頭にまだ解放していない係から好きなものを1種選んで解放していく（最大4種・2年1学期）。解放した係はずっと使える。
   係に就いた子は、その係のアイコンが2倍に数えられる。学期の頭に全クラスが一斉に決め直し、全員が「準備OK」になったら手番が始まる。
   プレイマットの左側にある4つの「係の場」に生徒のカードを置くと、その子がその係になる（ドラッグで動かすか、タップで持ち上げて置き場をタップ）。係の場どうし・係の場と座席のカードは入れ替わる。まだ解放していない係の場（🆕）をタップすると、その係を解放する。
3. **手番：場のカードを1枚取る**（プレイヤーは同じ学校の別のクラスの担任）
   - 卓の中央にカードが4枚、表向きで並んでいる（場）。手番の人はここから1枚取る。取りたいものがなければ1枚を捨てて見送ってもいい
   - **無料で取れる**：授業（📚数学・🏃体育・🎨美術・🙋学活の時間。クラス全員のそのアイコンの合計個数＋係ボーナスがその場で入る）・カチコミ👊（他のクラスを1つ選んで、自分の👊の数（＋係ボーナス）×3だけ減点させ、👊の数だけ自分に加点する（ドレイン）。👊を持つ子がいないと取れない）・クラス替え🔁（自分の生徒1人と、他のクラスの係に就いていない生徒1人を入れ替える。印刷されたアイコンの数が同じ子どうしだけ。グッズの＋1は数えない）
   - **クラスポイントを払って取る**：人物（カードに印刷されたアイコンの数で決まる：1個2点／2個4点／3個8点／4個14点／5個24点。短い試合ならアイコンの少ない安い子、長い試合なら多い子が狙い目。満席なら係に就いていない子を1人転校させて迎える）・グッズ（2点。生徒1人に装備してアイコン＋1、1人1つまで。共通3種＋時代ごとに2種。平安だけは竹取物語の5つの宝）・サイボーグ化（2点・未来のみ）。「今すぐ点を取るか、点を払って将来の戦力を買うか」が悩みどころ
   - 取ったら山札から場を補充する。このとき**ゲリラ**をめくったら、その場で起こる（誰も避けられない）。ゲリラは誰の手番でもない学校全体のできごとで、ゲリラの間は卓が紫に縁どられ、転校で選んでいる人には「📦 選んでいる」（手番の黄色い光ではない）、次の手番の人には「▶ 次の番」が出る
     - 共通イベント（全クラス）：抜き打ちテスト・授業参観・持久走大会・合唱コンクールは、時代イベントが出やすいように**いまは休止中**（山札に入らない）
     - 時代イベント（全クラス）：時代ごとにものを言う力が違う。現代・白亜紀・古代エジプト・ギリシャ・ローマ・三国志・平安・中世・戦国・江戸・近代・未来の全部が4種×1枚。山札の上のほうに学期を通して散らして入れるので、1学期にたいてい3枚前後めくられる（1枚目は必ず）
       - 現代 🎪文化祭（🎨を持つ子1人につき+2）／🏟️体育祭（🏃を持つ子1人につき+2）／🗳️生徒会長選挙（全校で👑が一番多い子が当選し、👑が1つ増える）／🚌修学旅行（アイコンの総数が12以上で+5、18以上で+10、24以上で+15）。文化祭・体育祭は合唱コンクール・持久走大会（休止中）の強い版
       - 白亜紀 ☄️巨大隕石の衝突（全クラス−8、🏃を持つ子1人につき+2）／🦖ティラノサウルスの狩り（👊が一番多いクラスが、ポイントが一番多いクラスから8点奪う。自分がポイント1位なら何もしない）／🦕大移動（👊6以上で+6）／🥚オヴィラプトルの卵泥棒（🏃が一番多いクラスの空いた席に卵が来て、そのクラスの次の手番の始めに恐竜が孵る。オヴィラプトル🏃：パラサウロロフス🏃🏃：スピノサウルス👊👊🏃 = 5:4:1）
       - 古代エジプト 🔺ギザの大ピラミッド建設（山札には入らず、学期のあいだ場の右に残る。手番で場のカードの代わりに選ぶと、クラスの🏃の数（＋係ボーナス）だけ石を積む（その手番は点なし）。全クラスの石が7×クラス数に届いたら完成：自分のクラスが積んだ石が7個以上なら+20、14個以上なら+30（7個未満は0）。学期が終わるまでに完成しなければ、積んだ石はむだ）／🌊ナイルの氾濫（🏃を持つ子1人につき+2の収穫）／👁️ヒエログリフ（🎨と📚を両方持つ子（書記）1人につき+3）／⚱️ミイラづくり（グッズを装備している子1人につき+4。あの世へ持っていく副葬品）
       - ギリシャ・ローマ 🏛️古代オリンピック（🏃の数で勝負：1位+12、2位+5、負けても減点なし）／⚔️コロッセオの剣闘（各クラスで🏃と👊の合計が一番多い子が戦う：1位+12、負けても減点なし）／🧔ソクラテスの問答（各クラスで📚が一番多い子が代表になってソクラテスと対話：代表の📚が4以上なら+8）／🏺陶片追放（全クラスが自分以外のクラスへ、ポップアップで1人ずつ秘密投票。票が一番多いクラス（同票ならポイントが多いクラス）が、係に就いていない子を1人転校させる。だれがどこに入れたかは最後まで出ない）
       - 三国志 ⛵赤壁の戦い（👊が一番多いクラス（大船団）と、それ以外で📚が一番多いクラス（軍師）の勝負。軍師の📚が大船団の👊より多ければ火攻めで大船団−10・軍師+10、届かなければ大船団+10・軍師−5。👊の一番が同点ならにらみ合い）／🏠三顧の礼（👑の数から📚の数を引いた差が一番大きいクラス（満席のクラスは除く）に、諸葛亮孔明📚📚📚👑が軍師として無料で転入する。孔明は人物カードの山には入らず、このイベントでしか来ない）／🌉長坂の戦い（ポイントが一番多いクラスが追いかける。ほかの各クラスは👊が一番多い子1人が橋に立ち、👊2以上なら一喝して追い返し、追いかけるクラスから4点奪う。ポイントの一番が同点ならにらみ合い）／🍑桃園の誓い（ポイントが一番少ないクラスが劉備役になり、ほかのクラスを2つまで選んで義兄弟になる。学期の区切りで、誓ってから義兄弟のクラスが得た点・失った点を合わせて山分けする）
       - 平安 📖源氏物語（全校で🎨が一番多い子が作者になり、作者のクラスで👑を持つ子1人につき+3）／🌕藤原道長の望月の歌（👑が一番多いクラスが宴に招かれて+6）／🌙竹取物語・かぐや姫の難題（かぐや姫が学期の終わりまで場に滞在し、平安のグッズ＝5つの宝🥣仏の御石の鉢📚・🐚燕の子安貝🏃・🌿蓬莱の玉の枝🎨・🔥火鼠の皮衣👑・🐉龍の首の珠👊から、どのクラスが差し出してもよい（各宝1回きり）。宝を装備した子がいれば自分の手番でいつでも差し出せ、場の宝を取ったときは装備せずにそのまま差し出してもよい（差し出すかどうかは選べる。差し出すと+5で宝は消え、手番はそのまま続く）。差し出せないまま学期が終わると、かぐや姫は月へ帰る）／🪓五条大橋の弁慶（👊の合計が3以上のクラスが弁慶を倒し、一番多いクラス（同点ならポイントが少ないクラス）に弁慶👊👊👊が家来として転入。弁慶は人物の山には入らず、このイベントでだけ仲間になる。義経は👊3なので1人でも必ず勝てる）
       - 中世・ルネサンス 🖼️モナ・リザ制作（各クラスの🎨が一番多い子1人の🎨の数×3）／📘活版印刷（📚を持っていない子全員の📚が1つ増える。全員持っていれば何も起こらない）／🐀ペストの大流行（各クラスの係に就いていない子1人がランダムにかかり、学期の区切りまで🏃を数えない。グッズは装備できる）／🌎コロンブスの新大陸到達（📚の多いクラスから順に、新大陸の品🍫カカオ👑・🌽トウモロコシ🏃・🍅トマト🎨・🗺️新大陸の地図📚から1つと、それを無料で装備させる子（グッズを持っていない子）を選ぶ。取られた品は次のクラスは選べず、4つなくなったら終わり）

     - 転校📦：全クラスが、係に就いていない生徒を1人ずつ必ず手放す（1枚だけ。山札に入るのは学期の3回に2回）

   - 人物カードは学期ごとに最大7枚（その時代のカードプールに残っている子だけ）。生徒はどの時代も有限で、人物ごとにアイコンの構成が被らないようにしてある
   - 山札の内訳（例：現代の学期、計41枚。転校が入らない学期は40枚）：授業19（📚5・🏃5・🎨5・👑4）／カチコミ3／転校1・クラス替え1／グッズ5（共通3＋時代2）／時代イベント4＋襲来1／人物7。ゲーム中は中央の「捨て札・内訳」で残り枚数を確認できる
4. **時代** — 1年に3つ、1学期に1つずつ巡る。現代もほかの時代と並列で、どれが来るかはランダム。何が有利かは数字ではなく、学期の頭に読み上げられる時代の空気（白亜紀なら「理屈も作法も通じない。強い者と、すばしこく逃げ回れる者だけが生き残る時代」）から読み取る。
5. **決まったイベント（全員）** — 学期末の定期テスト（📚の合計個数−👊を持つ子1人につき1で順位、5／3／2／1点）、最後に卒業式（クラス全員のアイコン総数、順位点×3）。8月は夏休みで手番なし。
6. 1年／2年／3年が終わった時点でクラスポイントが一番多い先生の勝ち。

## 生徒カード

書いてあるのは **アイコン**（📚勉強・🏃運動・🎨芸術・👑人望・👊喧嘩）だけ。同じアイコンが並ぶほど得意で、1枚に最大5個（N 1〜2個／R 2〜3個／SR 3〜4個／SSR 4〜5個）。グッズを装備すると1つ増える。中世の活版印刷・現代の生徒会長選挙・未来のシンギュラリティでも1つ増える（6個まで）。
👊はヤンキーだけが持ち、ヤンキーの約半分は👊のみ（たまに🏃や📚も持つ）。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # ゲームロジックのテスト（全員CPUで完走するシミュレーション含む）
npm run build   # dist/ に静的ファイルを出力
```

- `src/game/` — ゲームロジック（React非依存）。`engine.ts` が状態遷移、`ai.ts` がCPU思考
- `src/game/data/` — カード・時代・係・クラス・イベントのデータ。カードを増やすならここ
- `src/ui/` — 画面
- `src/net/` — 通信対戦。`host.ts` がルームを作った人の端末（ゲームを進めて全員に状態を配る）、`guest.ts` が参加した人の端末（操作を送る）、`protocol.ts` がやりとりの型と「今その人が操作してよいか」の判定、`relay.ts` が中継サーバーとのやりとり

通信対戦の中継サーバーを別の Supabase プロジェクトにする時は、ビルド時に `VITE_RELAY_URL`（プロジェクトのURL）と `VITE_RELAY_KEY`（公開用の publishable キー）を指定します。Supabase の無料プロジェクトは、しばらく使われないと休止するので、`.github/workflows/keepalive.yml` が3日ごとにアクセスして起こしておきます。

進行状況はブラウザの localStorage に自動保存され、タイトル画面の「続きから」で再開できます。
保存データの版（`src/game/saveVersion.ts` の `SAVE_VERSION`）は「形の版＋データの指紋」です。人物・イベント・グッズ・時代などのデータを変えると指紋が自動で変わり、前の版の保存データは読み込まれなくなります（名前や説明文だけの変更では変わりません）。GameState の項目の名前や意味を変えたときだけ、`SAVE_SCHEMA` を手で上げてください。
`main` ブランチへの push で GitHub Pages にデプロイされます（`.github/workflows/deploy.yml`）。
