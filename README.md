# 時空最強クラス決定戦 〜タイムトラベル・ティーチャー〜

歴史上の偉人や恐竜を自分のクラスに転校させて「時空最強のクラス」を作る、2〜5人用のボードゲームアプリ。
カタンの「自分の番でなくても毎回得点チャンスがある」感じと、桃鉄の「すごろく移動＋長期戦」を合わせたゲーム性です。

1台の端末を回して遊ぶホットシート式。CPUプレイヤーも入れられるので1人でも遊べます。

## 遊び方

1. **クラスカードを引く** — 7種のクラス（体育会系・ガリ勉・問題児の掃き溜め…）からランダムに1枚。
   係の構成と、最初の12人（全員現代の普通の生徒）が決まる。
2. **係を決める** — 学級委員長・体育委員・風紀委員・飼育係など。係についた生徒は能力にバフ。
   1年は3学期あり、学期の頭にだけ再編成できる。
3. **毎ターン**
   - サイコロを振ってタイムマシンを移動（白亜紀〜未来の11時代）
   - イベントカードを引く
     - 学校行事（体育祭・文化祭・抜き打ちテスト…）：全クラスが参加し、イベントに合う能力で順位を競う
     - 他校のヤンキー襲来：喧嘩上位3人で迎え撃つ。ヤンキー・武将・恐竜が頼りになる
     - 転校生：タイムマシンがいる時代から候補が現れ、1人を迎え入れる（偉人は1人しかいないので早い者勝ち）
     - 特訓・時空嵐・引き抜き・持ち物検査などのハプニング
4. **固定イベント** — 学期末の定期テスト（全員の平均学力。ヤンキーと恐竜は足を引っ張る）、
   夏休みのタイムトラベル合宿、進級、最後に卒業式（総合力審査）。
5. 1年／2年／3年が終わった時点でポイントが一番多い先生の勝ち。

## 能力値

運動・学力・喧嘩・芸術・人望の5つ。偉人カードには「クラス全員の学力+1」「委員長になると倍率×2」
「毎ターン+1pt」「失点軽減」などの特殊能力がついています。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # ゲームロジックのテスト（全員CPUで完走するシミュレーション含む）
npm run build   # dist/ に静的ファイルを出力
```

- `src/game/` — ゲームロジック（React非依存）。`engine.ts` が状態遷移、`ai.ts` がCPU思考
- `src/game/data/` — カード・時代・係・クラス・イベントのデータ。カードを増やすならここ
- `src/ui/` — 画面

進行状況はブラウザの localStorage に自動保存され、タイトル画面の「続きから」で再開できます。
`main` ブランチへの push で GitHub Pages にデプロイされます（`.github/workflows/deploy.yml`）。
