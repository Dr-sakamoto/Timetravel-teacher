# 時空最強クラス決定戦 〜タイムトラベル・ティーチャー〜

歴史上の偉人や恐竜を自分のクラスに転校させて「時空最強のクラス」を作る、2〜5人用のボードゲームアプリ。
カタンの「自分の番でなくても毎回得点チャンスがある」感じと、桃鉄の「すごろく移動＋長期戦」を合わせたゲーム性です。

1台の端末を回して遊ぶホットシート式。CPUプレイヤーも入れられるので1人でも遊べます。

**遊ぶ：https://timetravel-teacher.vercel.app/** （PWA対応。Chrome/Edgeのアドレスバーの「インストール」でPCアプリとして使え、オフラインでも動きます）

## 遊び方

1. **最初の6人を引く** — 全員で順番に「現代の生徒」の山札から1枚ずつ、完全ランダムに引く。教室の12席のうち6席が埋まった状態でスタート。
2. **係を決める** — 係は全員共通（✏️学習係📚・🏅体育委員🏃・🖌️文化委員🎨・🎖️学級委員長👑・🛡️風紀委員👊・📖図書委員📚）。
   6人で3つ、8人で4つ、10人で5つ、12人で6つ使える。係のアイコンを持つ子を就けると、そのアイコンで点が入るたび+1。学期の頭に決め直せる。
3. **手番：1人1枚ずつイベントの山札をめくる**（通常カードは全員に、イベントカードはめくった人だけに効果）
   - 通常カード（全員）：授業・部活動・音楽…。そのアイコンを持つ子1人につき+1。全クラスが数える
   - イベントカード（めくった人だけ）：体育祭・文化祭・球技大会・合唱・抜き打ちテスト・生徒会選挙。そのアイコンを持つ子の数値の合計（＋係ボーナス）が入る
   - カチコミ（めくった人だけ）：👊の数値の合計が敵の強さ以上なら+6、足りなければ−4
   - 転入：今学期の時代の山札から3枚めくって1人を迎える（偉人は1人しかいないので早い者勝ち）
   - 転校：いらない生徒を別のクラスに押しつける
   - 時代カード（めくった人だけ）：イベントカードと同じ。ただしその時代出身の生徒は数値2倍（科挙・天下分け目の合戦・恐竜レースなど各時代2種）
4. **時代** — 1年ごとに3つの時代がランダムに決まり、1学期に1つずつ巡る。山札は共通カード＋その学期の時代カード。
5. **決まったイベント（全員）** — 学期末の定期テスト（📚の数値の合計−👊1人につき2で順位、10／6／3／1点×2）、8月の夏休み合宿、最後に卒業式（全員の数値の合計、順位点×3）。
6. 1年／2年／3年が終わった時点でクラスポイントが一番多い先生の勝ち。

## 生徒カード

左上の **数値（1〜5）** と、下段の **属性アイコン**（📚勉強・🏃運動・🎨芸術・👑人望・👊喧嘩）だけ。
👊はヤンキーだけが持ち、ヤンキーは📚を持たない。属性の幅は通常カードで、数値の高さはイベントカードとテストで効く。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # ゲームロジックのテスト（全員CPUで完走するシミュレーション含む）
npm run build   # dist/ に静的ファイルを出力
```

- `src/game/` — ゲームロジック（React非依存）。`engine.ts` が状態遷移、`ai.ts` がCPU思考
- `src/game/data/` — カード・時代・係・クラス・イベントのデータ。カードを増やすならここ
- `src/ui/` — 画面

進行状況はブラウザの localStorage に自動保存され、タイトル画面の「続きから」で再開できます。
`main` ブランチへの push で GitHub Pages にデプロイされます（`.github/workflows/deploy.yml`）。
