# 時空最強クラス決定戦 〜タイムトラベル・ティーチャー〜

歴史上の偉人や恐竜を自分のクラスに転校させて「時空最強のクラス」を作る、2〜5人用のボードゲームアプリ。
カタンの「自分の番でなくても毎回得点チャンスがある」感じと、桃鉄の「すごろく移動＋長期戦」を合わせたゲーム性です。

1台の端末を回して遊ぶホットシート式。CPUプレイヤーも入れられるので1人でも遊べます。

**遊ぶ：https://timetravel-teacher.vercel.app/** （PWA対応。Chrome/Edgeのアドレスバーの「インストール」でPCアプリとして使え、オフラインでも動きます）

スマホは**横向き**で遊ぶ想定です（卓全体が1画面に収まります。縦向きだと横にするよう案内が出ます）。

画面には自分の教室と、手番の人の教室だけが出ます。ほかの人の教室は小さく畳まれていて、タップするとポップアップで見られます。

## 遊び方

1. **最初の6人を引く** — 全員で順番に「現代の生徒」の山札から1枚ずつ、完全ランダムに引く。教室の12席のうち6席が埋まった状態でスタート。
2. **係を決める** — 係は全員共通（✏️学習係📚・🏅体育委員🏃・🖌️文化委員🎨・🎖️学級委員長👑・🛡️風紀委員👊・📖図書委員📚）。
   最初の学期は3つで、学期が進むごとに1つずつ増える（1年1学期3つ→2学期4つ→3学期5つ→2年1学期で6つ）。1人が就ける係は1つまで。係に就いた子は、その係のアイコンが2倍に数えられる（📚の係なら、その子の📚が2倍）。学期の頭に決め直せる。
3. **手番：1人1枚ずつ山札をめくる**（通常カードは全員に、それ以外はめくった人だけに効果）
   - 通常カード（全員）：そのアイコンを一番多く持つ子1人の個数（＋係ボーナス）が入る。カードの中身は全時代共通で、名前と絵柄だけ時代で変わる（📚なら現代は「授業」、平安は「漢詩の勉強」）
   - イベントカード（めくった人だけ）：体育祭・文化祭・球技大会・合唱・抜き打ちテスト・生徒会選挙＋時代の固有イベント2種。クラスのそのアイコンの合計個数（＋係ボーナス）が入る。固有イベントはその時代出身の子のアイコンが2倍
   - カチコミ（めくった人だけ）：クラスの👊の合計個数が敵の強さに足りない分だけマイナス（プラスはなし）。攻めてくる敵は時代ごとに変わる（他校のヤンキー、肉食恐竜の群れ、野武士の群れ…）
   - 人物カード：めくったらその子がそのまま転入（学期ごとに7枚。その時代の偉人が足りない分は現代の生徒）。満席なら捨て札にしてもう1枚めくる
   - 転校（めくった人だけ）：いらない生徒を別のクラスに押しつける
4. **時代** — 1年に3つ、1学期に1つずつ巡る。1年目の1学期は現代、あとはランダム。各時代に固有の偉人5〜6人・固有イベント2種・固有のカチコミと通常カードの絵柄がある。
5. **決まったイベント（全員）** — 学期末の定期テスト（📚の合計個数−👊1人につき1で順位、5／3／2／1点×2）、8月の夏休み合宿（2学期の時代から全員に1人ずつランダムに転入）、最後に卒業式（クラス全員のアイコン総数、順位点×3）。
6. 1年／2年／3年が終わった時点でクラスポイントが一番多い先生の勝ち。

## 生徒カード

書いてあるのは **アイコン**（📚勉強・🏃運動・🎨芸術・👑人望・👊喧嘩）だけ。同じアイコンが並ぶほど得意で、1枚に最大5個（N 1〜2個／R 2〜3個／SR 3〜4個／SSR 4〜5個）。数字を足す代わりにアイコンを数えるだけで遊べ、点は外周のスコアトラック（0〜100、1年でだいたい1周）で数える想定。
👊はヤンキーだけが持ち、ヤンキーの約半分は👊のみ（たまに🏃や📚も持つ）。通常カードは「一番多く持つ子1人の個数」、イベントカードとテストは「クラスの合計個数」を数える。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # ゲームロジックのテスト（全員CPUで完走するシミュレーション含む）
npm run build   # dist/ に静的ファイルを出力
```

- `src/game/` — ゲームロジック（React非依存）。`engine.ts` が状態遷移、`ai.ts` がCPU思考
- `src/game/data/` — カード・時代・係・クラス・イベントのデータ。カードを増やすならここ
- `src/ui/` — 画面

進行状況はブラウザの localStorage に自動保存され、タイトル画面の「続きから」で再開できます。
`main` ブランチへの push で GitHub Pages にデプロイされます（`.github/workflows/deploy.yml`）。
