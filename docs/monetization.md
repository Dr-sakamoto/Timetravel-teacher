いまは**お金がたまるまで収益化を凍結**する。そのあいだに、お金がかからない準備をすべて済ませて、「あとはお金さえあれば」の状態にしておく。

金額は 2026年10月時点で調べたもの（1ドル＝150円で換算）。⚠️ の付いた金額は、申し込む前に公式の料金ページで確かめること。

**段階1（3,000円）→ テストプレイでルールを固める → 段階3（クラウドファンディング・0円）** の順で進める。印刷代のような大きなお金は、支援してくれた人から先に集める。自分のお金がほぼ要らないのはこの道だけ。

## 2. サーバー代の落とし穴（お金を受け取り始める前に必ず読む）

- **Vercel の無料プラン（Hobby）は、商用で使ってはいけない。** サイトで物を売る・広告を出す・販売ページへ案内する、と決めた時点で Pro（月 $20 ≈ 3,000円）が要る。
  - 代わりに **Cloudflare Pages の無料プランは商用でも使える**ので、移せばここは0円にできる（ビルドは `npm run build` の `dist/` をそのまま載せるだけ）。⚠️ 移す前に規約を確かめる
- **Supabase（通信対戦の中継）の無料プラン**は、同時接続が200まで・メッセージが月200万通まで。しばらく使われないと休止もする。人気の実況者に紹介されると上限を超えて、つながらなくなるおそれがある。超えそうになったら Pro（月 $25 ≈ 3,750円）にする。
  - 通信対戦の同時接続は、だいたい「遊んでいる人数」と同じ。200 は「同時に40〜60卓」くらい。
- 合計：Vercel Pro＋Supabase Pro で**月 約7,000円**。Cloudflare Pages に移すなら**月 約3,750円**。人が来るまでは Supabase も無料のままでよい。
