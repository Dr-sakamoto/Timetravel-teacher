# 紙の試作品の作り方（約3,000円）

テストプレイ用の試作品を作る。目的は「アプリが自動でやっている点数計算を、人の手でやっても楽しいか」を確かめること。ここが紙の製品版の一番の山場になる。

## 1. 印刷データを出す
1. アプリを `#print` を付けて開く（例：`https://timetravel-teacher.vercel.app/#print`）
2. 「🖨️ 印刷する（PDFに保存も）」を押す
3. 印刷の設定で次を選ぶ：
   - 送り先：**PDFに保存**
   - 用紙：A4
   - 倍率：**100%（実際のサイズ）**。「用紙に合わせる」にしない
   - 余白：**なし**
   - **背景のグラフィック：オン**
4. 全205枚が A4 23枚の PDF になる（ポーカーサイズ 63×88mm が9枚ずつ。点線で切る）

## 2. 刷る・切る（金額は目安）
| もの | 目安 |
|---|---|
| コンビニのネットプリントで A4カラー×23枚 | 約1,400〜1,800円 |
| カードスリーブ（63.5×88mm 用）×約210枚 | 約1,000〜1,500円 |
| 100円ショップのトランプ×4組（スリーブの中で、紙の裏に入れて硬さを出す） | 約440円 |
| **合計** | **約3,000円** |

- 普通紙を切ってスリーブにトランプと一緒に入れると、厚紙を買わなくても混ぜたり配ったりできる
- 家のプリンタがあればインク代だけで済む

## 3. アプリにはあるが、紙では足りないもの（手で用意する）
- **時代**：学期ごとに時代を1つ引く。紙に11時代を書いて、くじにする
- **係**：4種類（👑学級委員長・🎨文化委員・📚学習係・🏃体育委員）を紙に書いて、生徒カードの上に置く
- **クラスポイント**：紙とペンでメモする（点数が0未満にならないことに注意）
- **定期テスト・卒業式**：7月・12月・3月の終わりに、クラスのアイコンを数えて順位を決める
- **山札づくり**：学期ごとに「全時代のカード」＋その時代のカード＋その時代の人物を混ぜる（人物は最大7枚）。転校は3回に2回だけ入れる

## 4. テストプレイで記録すること（5回以上）
- 1ゲームにかかった時間（アプリの1年で約30分。紙ではどれくらい延びるか）
- 点数の計算でいちばん手間取ったカード → 紙版では数字を簡単にするか、外す候補
- 盛り上がった場面（どのイベント・どの偉人）→ クラウドファンディングのページと動画に使う
- 「また遊びたい」「いくらなら買うか」を遊んだ人に聞く

## 注意
- `カツ`（現代の生徒）は実在の人の写真を使っている。人に見せたり売ったりする前に、本人の同意をとるか、絵に差し替える
